====================================================
  Media Catch（媒体抓取器）安装说明
  适用于 Microsoft Edge / Google Chrome（Manifest V3）
====================================================

【安装步骤】

1. 将本压缩包解压到一个固定文件夹
   （例如 D:\ext\edge_media_catch_ext，解压后文件夹里应包含 manifest.json）

2. 打开 Edge 浏览器，地址栏输入并回车：
   edge://extensions
   （Chrome 用户输入：chrome://extensions）

3. 打开页面右上角（或左下角）的「开发人员模式」开关

4. 点击「加载解压缩的扩展」按钮，选中刚才解压的文件夹
   （注意：选中包含 manifest.json 的那一层文件夹）

5. 安装成功后，浏览器工具栏会出现扩展图标

6. 打开任意含视频/图片的网页，点击工具栏图标即可查看抓取到的媒体资源


【重要提醒】

- 解压后的文件夹不能删除或移动，否则扩展会失效
- 修改代码后，回到 edge://extensions 点扩展卡片上的「重新加载」(↻) 生效
- 本扩展仅抓取网页中公开可访问、未加密的媒体资源
- 仅供个人学习与研究使用，下载内容请遵守版权法律法规

【遇到问题】

- 加载失败：确认选中的文件夹里有 manifest.json
- 图标不显示：在 edge://extensions 确认扩展已启用
- 更多帮助：https://github.com/HELIX-AISTUDIO/media-capture-extension/issues
